# Droply

A fast, simple and privacy-friendly way to transfer files between devices.

Upload a file, get a short URL, and download it from any device. No account required.

>  This project is currently under development.

##  Features

-  Fast file uploads
-  Short and easy-to-share URLs
-  Temporary download links
-  Automatic file deletion after expiration
-  Works on any device with a web browser
-  No account required
-  Simple and lightweight

##  Planned Features

- Custom expiration time
- Password-protected links
- Download limits
- QR code generation
- Drag & Drop upload
- Upload progress bar
- File previews
- API for developers
- Dark mode

##  Tech Stack

- Node.js
- Express.js
- HTML
- CSS
- JavaScript

##  Project Status

This project is in active development and is not ready for production use.
